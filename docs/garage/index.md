## ¿Tu auto está aquí?

Si eres miembro del club y tienes un Swift GTi / Cultus / Forsa / Swift GT — **podemos documentarlo aquí**.

### Información que pedimos
- 📸 Fotos (mínimo: frontal, trasera, lateral, motor, interior, cualquier detalle especial)
- 📋 Specs: año, color, variante, kilometraje aproximado
- 📅 Historia: cuándo llegó al club, modificaciones realizadas, eventos especiales
- 👤 Owner (opcional): nombre, contacto si quieres recibir mensajes
- 🔧 Build progress (opcional): si está en restauración

### Cómo subir tu auto
1. Únete al [Telegram del club](../comunidad/telegram.md)
2. Posta tu auto en el topic "🚙 Builds en progreso"
3. Etiqueta a un admin para crear la página dedicada
4. Recibes link a tu URL personal: `suzukigti.github.io/garage/<tu-auto>/`

## Plantilla disponible para nuevos autos

Cada página de auto sigue esta estructura estándar:

```
- Foto hero principal
- Ficha técnica rápida (año, color, motor, transmisión, mods)
- Historia narrativa
- Galería de fotos
- Modificaciones detalladas
- Línea temporal de eventos importantes
- Documentos (registro, calcomanías, etc.)
- Contacto del owner (opcional)
```

Si quieres ver un ejemplo completo terminado, mira [Verto](verto.md).
