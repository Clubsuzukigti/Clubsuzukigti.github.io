## Tu auto merece estar aquí {#tu-auto}

!!! tip "SLOT 87 ABIERTO"
    Si eres miembro del club y tienes un Swift GTi / Cultus / Forsa / Swift GT / Geo Metro con conversión — **podemos documentarlo aquí**. Sin importar si es daily driver, restauración en proceso, build de carreras o convertible único. Cada auto que documentamos es uno que no se pierde en el olvido.

### Información que pedimos
- 📸 **Fotos:** frontal, trasera, lateral, motor, interior, cualquier detalle especial
- 📋 **Specs:** año, color, variante, kilometraje aproximado
- 📅 **Historia:** cuándo llegó al club, modificaciones realizadas, eventos especiales
- 👤 **Owner** (opcional): nombre, contacto si quieres recibir mensajes
- 🔧 **Build progress** (opcional): si está en restauración

### Cómo subir tu auto

[Enviar mi proyecto por Telegram →](../comunidad/telegram.md){ .md-button .md-button--primary }
[Escribir al equipo →](../contacto.md){ .md-button }

1. Únete al [Telegram del club](../comunidad/telegram.md)
2. Posta tu auto en el topic **"🚙 Builds en progreso"**
3. Etiqueta a un admin para crear la página dedicada
4. Recibes link a tu URL personal: `clubsuzukigti.github.io/garage/<tu-auto>/`

## Plantilla disponible para nuevos autos {#plantilla}

Cada página de auto sigue esta estructura estándar:

- Foto hero principal
- Ficha técnica rápida (año, color, motor, transmisión, mods)
- Historia narrativa
- Galería de fotos
- Modificaciones detalladas
- Línea temporal de eventos importantes
- Documentos (registro, calcomanías, etc.)
- Contacto del owner (opcional)

Si quieres ver un ejemplo completo terminado, mira [Verto](verto.md).
