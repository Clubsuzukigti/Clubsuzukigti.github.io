# ECU standalone

<div class="gti-quote" markdown>
*La ECU stock del GTi es honesta hasta cierto punto. Cuando empiezas a meter turbo o cams agresivos, te pide jubilarse.*

<cite>— ECU STANDALONE · MS · HALTECH · AEM</cite>
