# Cultus GTi JDM

<div class="gti-quote" markdown>
*En Japón se llamó Cultus. Tres códigos de carrocería. Tres variantes con el mismo G13B JDM más potente del mundo.*

<cite>— CULTUS GTi · JDM 1989-2002</cite>
</div>

En el mercado japonés el modelo se vendió como **Cultus GTi** con tres códigos de carrocería distintos. El motor G13B JDM tenía especificación superior a la export: **115 PS JIS, CR 11.5:1, headers tubulares de fábrica**. Sólo en Japón.
