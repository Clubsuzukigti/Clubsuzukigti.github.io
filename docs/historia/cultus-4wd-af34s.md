# Cultus GT-i 4WD AF34S

<div class="gti-quote" markdown>
*El mismo G13B JDM de 115 PS. La misma carrocería SF413. Pero con tracción integral. Solo para Japón. Solo unos pocos miles producidos. La rareza absoluta del modelo.*

<cite>— AF34S · JDM EXCLUSIVO · 1990-1994</cite>

El **Suzuki Cultus GT-i 4WD** (código de carrocería **AF34S**) es la variante más rara y deseada de toda la familia Swift GTi. Producido exclusivamente para el mercado japonés entre 1990 y 1994, combina el motor JDM G13B de 115 PS con un sistema de tracción integral 4WD.

## El sistema 4WD {#sistema-4wd}

El AF34S usa un **viscous coupling LSD** entre el eje delantero y el trasero. En condiciones normales el sistema funciona prácticamente como FWD (eficiencia de combustible), pero al detectar slip se acopla el eje trasero hasta 40% del torque.

- **Caja transfer:** integrada al transaxle, ratio 1:1
- **Diferencial central:** viscous coupling (no center diff convencional)
- **Diferencial trasero:** abierto estándar
- **Eje trasero:** doble rótula independiente con muelles helicoidales

Este sistema fue raro incluso para Suzuki — usado en pocos otros modelos JDM como el Escudo. La complejidad mecánica + bajo volumen produjeron baja sobrevivencia.

<hr class="gti-rule">

## Por qué tan pocos sobreviven {#sobrevivencia}

1. **Producción minúscula:** estimados <5,000 unidades total en 4 años
2. **JDM only:** sin exportación legal hasta cumplir 25 años (USA rule)
3. **Complejidad transfer case:** falla = motor descompuesto + tracción rota
4. **Repuestos transfer case:** virtualmente imposibles fuera de Japón
5. **Canibalización:** muchos convertidos a FWD y partes vendidas individualmente
6. **Sobrevivencia actual:** estimada <300 unidades funcionales worldwide

<hr class="gti-rule">

## Cómo identificarlo {#identificacion}

- **VIN:** comienza con `AF34S-` (no SF413)
- **Placa firewall:** model code `AF34S` impreso
- **Visualmente:** eje trasero independiente visible bajo el auto (no barra antitorsión)
- **Etiquetas:** badges originales "**GT-i 4WD**" o "**Twin Cam 16 Valve · 4WD**" en costados
- **Interior:** indicador 4WD en cluster de instrumentos (cuando se acopla el eje trasero)

⚠ **Cuidado con clones:** existen builds homemade que convierten Swift GTi FWD a AF34S spec falsificado. Verificar siempre VIN + placa firewall + diferencial trasero real.

<hr class="gti-rule">

## Donde encontrarlos {#donde-encontrar}

- **Japón:** subastas USS/HAA/JU, exportadores Nengun + Be-Forward
- **Australia/Nueva Zelanda:** importadores JDM 25-year rule (más estricto)
- **USA:** legal desde 2015-2019 según año exacto del auto (25-year import rule)
- **Europa:** importación complicada; varios en colección privada UK
- **LatAm:** prácticamente cero

Precios actuales (2026):
- Buenas condiciones: **$8,000 - $18,000 USD**
- Excepcional / restaurado: **$25,000+ USD**
- Proyecto incompleto: **$3,000 - $6,000 USD**
