# SF413 GTi Service Manual

<div class="gti-quote" markdown>
*586 páginas. 24 secciones. El documento oficial que Suzuki produjo y luego dejó morir en bibliotecas técnicas. Aquí lo preservamos.*

<cite>— MANUAL OFICIAL · PUB. 99500-64B01</cite>
</div>

El **Suzuki Service Manual SF413 GTi** es el documento técnico oficial publicado por Suzuki Motor Corporation para los Swift GTi de la generación MK2 (modelo SF413 con motor G13B DOHC 16V). Este manual es la fuente primaria para mantenimiento, diagnóstico y reparación de todos los sistemas del vehículo.

## Estructura del manual {#estructura}

Las 24 secciones siguen la nomenclatura estándar de Suzuki:

| Sección | Contenido |
|---|---|
| 0A | General information |
| 0B | Maintenance and lubrication |
| 1A | Heating and ventilation |
| 1B | Air conditioning |
| **3A** | **Front suspension** |
| **3B** | **Rear suspension** |
| 3C | Wheels and tires |
| 3D | Front wheel drive shafts |
| 3E | Wheel alignment |
| 3F | Steering |
| **5A** | **Service brakes** |
| 5B | Parking brakes |
| **6A** | **Engine mechanical (G13B)** |
| **6B** | **Engine cooling** |
| 6C | Engine fuel |
| **6D** | **Engine exhaust** |
| **6E** | **Engine and emission control (EFI)** |
| 6F | Engine ignition system |
| 6G | Engine cranking system |
| 6H | Engine charging system |
| **7A** | **Manual transaxle** |
| 7B | Clutch |
| 8 | Body electrical system |
| 9 | Body service |
| 10 | Restraint system |

Las secciones marcadas son las **más consultadas** por el club. Los sistemas mecánicos del motor (6A-6H) son el corazón del archivo técnico.
