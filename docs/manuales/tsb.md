# TSB oficiales Suzuki

<div class="gti-quote" markdown>
*Los TSB son los ajustes que Suzuki documentó después de descubrir problemas reales en producción. Más confiables que cualquier blog.*

<cite>— TSB · TECHNICAL SERVICE BULLETIN OFICIAL</cite>
</div>

Los **Technical Service Bulletins** son los documentos oficiales que Suzuki publica para que mecánicos actualicen procedimientos después de descubrir patrones en producción. El TSB G13B Engine Adjustments (©1996) es la biblia para tunear el motor a especificación oficial.
