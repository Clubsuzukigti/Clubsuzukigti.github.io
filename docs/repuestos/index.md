## 🎯 Recomendación estratégica por región

### Si vives en **USA / Centroamérica**
1. eBay USA primero (stock + envío)
2. Cross-border Canadá si es ganga
3. JDM directo Nengun para partes raras

### Si vives en **Europa / UK**
1. eBay UK + Dansts Engineering
2. AutoDoc + Motor Doctor para partes carrocería
3. SuzukiRD para LSD premium

### Si vives en **LatAm (GT/Colombia/Ecuador/Argentina)**
1. MercadoLibre local
2. Facebook groups regionales (Twincam Bogotá, Forsa Ecuador)
3. Pakistan via Suzuki Fort Motors (envíos accesibles)
4. eBay USA solo para items grandes (engines)

### Si vives en **Australia**
1. eBay AU + Ozmotorsport
2. Blusteele para clutches
3. Importar JDM via Nengun

### Si vives en **Pakistán / Sri Lanka / Indonesia**
1. Mercado local masivo — Suzuki Fort Motors, NDEStore
2. PakWheels classifieds
3. Toda la cadena de suministro del Cultus aún activa
