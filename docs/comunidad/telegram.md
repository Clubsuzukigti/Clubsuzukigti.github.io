## Por qué Telegram y no Discord/WhatsApp {#por-que-telegram}

- **Topics:** organización por temas dentro de un solo grupo (no necesitas múltiples chats)
- **Búsqueda potente:** encuentras lo que se discutió hace 6 meses
- **Canal broadcast separado** para Manuales (descarga sin distracciones)
- **Cross-platform:** móvil, desktop, web — sincronizado
- **Sin algoritmo:** ves todo en orden cronológico, no en orden "engagement"

<hr class="gti-rule">

## Estructura propuesta del grupo

El grupo principal usa la función **Topics** de Telegram para organización clara:

| Topic | Uso |
|---|---|
| 📢 **Anuncios** | Solo admins postean — novedades importantes |
| 💬 **General** | Chat libre, presentaciones, off-topic ligero |
| 🛒 **Compra-Venta Repuestos** | Mercado interno del club |
| 🔧 **Reparación motor / mecánica** | Preguntas técnicas, diagnósticos |
| ⚡ **Modificaciones / Tuning** | Builds en progreso, ideas |
| 🚙 **Builds en progreso** | Hilos largos de proyectos |
| 📅 **Eventos / Meetups** | Track days, reuniones, exhibiciones |
| 🆘 **SOS Taller** | Urgencias mecánicas |
| ☕ **Off-topic** | Cualquier otro tema |

## Canal separado: 📚 Manuales

**Canal broadcast** (solo admins postean, miembros descargan):
- Manuales Suzuki originales
- TSBs oficiales
- Wiring diagrams
- Documentos del club

Acceso por aprobación del admin tras unirte al grupo principal.

## Reglas del grupo

1. **Respeto a todos los miembros** — diferencias de opinión sí, faltas de respeto no
2. **Solo contenido relacionado al Swift GTi / Cultus / Forsa / Swift GT** en topics técnicos
3. **Ventas:** indicar país + precio + condición + fotos reales
4. **No spam ni promoción ajena al modelo** sin autorización admin
5. **No reposts de noticias falsas** — verificar antes
6. **Español universal** preferido en mensajes técnicos para que todos entiendan (pan-hispánico)

## Cómo unirte

1. Tener app Telegram instalada
2. Esperar al link de invitación (próximamente aquí)
3. Presentarte en topic "💬 General" con:
   - Tu nombre
   - País
   - Año / variante de tu Suzuki (o "buscando comprar")
   - Foto (opcional pero ayuda a integrarte rápido)

Una vez aprobado, recibes acceso completo a todos los topics + canal de Manuales.

## Alternativa: GitHub Discussions

Para preguntas técnicas que merezcan quedar **archivadas y buscables permanentemente**, usamos el [foro GitHub Discussions](https://github.com/Clubsuzukigti/Clubsuzukigti.github.io/discussions) del proyecto.

**Cuándo usar GitHub Discussions vs Telegram:**

| Usa Telegram para... | Usa GitHub Discussions para... |
|---|---|
| Chat rápido | Pregunta técnica que merece quedar archivada |
| Fotos urgentes del taller | Tutoriales con varias respuestas |
| "Vendo turbo" | "Cómo hago X — paso a paso" |
| Eventos próximos | Recetas de modificación largas |
| Compra-venta urgente | Documentación que otros buscarán meses después |
