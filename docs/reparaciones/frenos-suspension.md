# Frenos y suspensión

<div class="gti-quote" markdown>
*Si no compras buenos frenos, estás ahorrando dinero a costa de tu seguridad.*

<cite>— FRENOS + SUSPENSIÓN · STOCK + UPGRADES</cite>
</div>

Mantener el sistema de frenos y suspensión del Swift GTi en spec es crítico. Los discos delanteros ventilados 233mm son adecuados para el peso del auto, pero los componentes se desgastan: pastillas, mangueras, bujes, tie rods, ball joints. Ignorarlos compromete la seguridad.
